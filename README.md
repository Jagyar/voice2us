# Voice2Us

Голосовой чат с друзьями. Звук идёт **напрямую** между вашими компьютерами,
без регистрации и аккаунтов. macOS и Windows.

- **Знакомство один раз.** Пригласили друга коротким кодом (`K7QM2-XPD9T`) —
  дальше он навсегда в вашем списке: нажали «Позвонить» и говорите.
- **Статус в реальном времени.** В списке видно, кто в сети, кто в разговоре,
  а входящий звонок показывается всплывающим окном.
- **Звук без потерь.** Несжатый PCM 48 кГц, минимальная задержка,
  трафик ~0,8 Мбит/с. Микрофон и динамик можно выбрать ещё до звонка;
  наушники, подключённые по ходу дела, подхватываются сами.
- **Шифрование.** ChaCha20-Poly1305 (как в WireGuard и TLS 1.3); каждый
  звонок получает свежие ключи.

## Как пользоваться

1. Скачайте свою сборку со страницы [Releases](../../releases/latest):
   `.dmg` для macOS, `.exe` для Windows (портативный файл, установки нет).
2. Один нажимает **«Пригласить друга»** и передаёт появившийся код —
   голосом или в мессенджере. Второй нажимает **«У меня есть код»** и вводит
   его. Код действует 10 минут и одноразовый.
3. Всё. Друг появился в списке. Дальше — **«Позвонить»**; у друга появится
   окно «звонит», он нажимает «Ответить». Смена IP-адреса у кого-то из вас
   ничему не мешает.

Окно спокойно живёт на заднем плане: пока приложение запущено, друзья видят
вас в сети и могут позвонить.

### macOS: «Apple не удалось подтвердить…»

Приложение не подписано сертификатом Apple, поэтому скачанная версия
помечена карантином. Один раз после копирования в «Программы»:

```bash
xattr -dr com.apple.quarantine /Applications/Voice2Us.app
```

(или «Системные настройки → Конфиденциальность и безопасность → Всё равно
открыть»). На Windows SmartScreen: «Подробнее → Выполнить в любом случае».

## Что делает сервер и что он видит

Сервис-«встречалка» (`cmd/rendezvous`, ~300 строк, без базы данных) нужен
только для знакомства, статуса и вызовов. **Звук через него не идёт.**

- Хранит в памяти непрозрачные зашифрованные блоки: приглашения — 10 минут,
  статусы — до 45 секунд. На диск и в логи ничего не пишется.
- Не знает ни имён, ни ключей: блоки шифруются на клиенте (код приглашения
  защищён `scrypt`, статусы — ключом дружбы). Друзья известны серверу только
  по случайным идентификаторам.
- Видит IP-адреса подключающихся клиентов и то, *что* кто-то онлайн.
- Работает по обычному HTTP: перехватчик в сети может помешать (например,
  отправив ложный блок), но прочитать ничего не может.

Адрес сервера меняется в приложении: «Профиль и сервер». Если сервер
недоступен, «Позвонить» пробует сохранённые адреса (друг тоже должен нажать
кнопку), а вместо приглашения работает **«Обмен кодами вручную»**.

Свой сервер: `go build ./cmd/rendezvous && ./rendezvous -addr :8787`.

## Если связь не установилась

Прямое соединение (пробитие NAT) работает в подавляющем большинстве домашних
сетей. Не получится, если у **обоих** симметричный NAT (типично для мобильного
интернета) или провайдер блокирует UDP между абонентами.

## Сборка

Нужны: Go 1.26+, Xcode CLT (macOS), mingw-w64 (для сборки .exe с мака).

```bash
./build.sh              # dist/Voice2Us.dmg (universal) и dist/Voice2Us.exe
./build.sh mac          # только macOS
VERSION=2.1.0 ./build.sh mac
```

Полезно: `./voice2us --devices` — напечатать список аудиоустройств и выйти.

## Выпуск релиза

Релизы собирает GitHub Actions: запушьте тег — на странице Releases появятся
`.dmg` и `.exe`. Теги вида `v2.0.0-rc.1` выходят как предварительные.

```bash
git tag v2.0.0 && git push origin v2.0.0
```

## Тесты

```bash
go test ./...
```

Сессия «Аня ↔ Боря» по UDP-петле, протокол и шифрование, сервер-«встречалка»
(сроки, лимиты, ошибки), приглашение по коду и вызовы друзей от начала до
конца. Снимки интерфейса в PNG: `V2U_SHOTS=/tmp/shots go test -run TestRenderScreens .`

## Как устроено (кратко)

- `internal/stun` — минимальный STUN-клиент (RFC 5389).
- `internal/proto` — код подключения, шифрование (отдельные ключи на
  направление и на сессию, окно анти-replay), сессия: пробитие NAT, keepalive,
  ping/pong, bye.
- `internal/rdv` + `cmd/rendezvous` — «встречалка»: сервер, клиент, криптография
  приглашений и статусов.
- `internal/audio` — miniaudio: захват и воспроизведение на независимо
  выбранных устройствах, кольцевые буферы, джиттер-буфер.
- `ui.go`, `calls.go`, `pairflow.go`, `presence.go`, `friend.go`, `theme.go` —
  интерфейс на Fyne, друзья, звонки, статусы.

Пакет в сети: `[8 байт эпохи][4 байта счётчика][ChaCha20-Poly1305-шифротекст]`,
nonce неявный (направление + счётчик), ключи выводятся из ключа дружбы через
HKDF с солью-эпохой сессии. Повторы и устаревшие пакеты отбрасываются.
