# Voice2Us

Голосовой чат на двоих, работающий напрямую между двумя компьютерами — без
серверов, без регистрации, без того, что можно заблокировать. macOS и Windows.

- **Шифрование**: ChaCha20-Poly1305 (тот же шифр, что в WireGuard и TLS 1.3),
  ключ сессии генерируется на месте и живёт один разговор.
- **Транспорт**: обычный UDP между вашими машинами. Пробитие NAT — через
  публичные STUN-серверы (в списке есть российские). Никаких релеев.
- **Звук**: несжатый PCM 48 кГц (моно) — качество без потерь, задержка
  минимальная. Трафик ~0,8 Мбит/с — меньше, чем любое онлайн-видео.
- **Без центральной точки**: сигналинг — обмен «кодами подключения» через
  любой мессенджер. Блокировать нечего.

## Как пользоваться

1. Каждый скачивает свою сборку (`dist/`): `Voice2Us.app` для macOS,
   `Voice2Us.exe` для Windows.
2. macOS: правый клик по приложению → «Открыть» (один раз, приложение без
   сертификата). При первом запуске разрешить доступ к микрофону.
   Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае».
3. **Один** игрок нажимает «Создать код», отправляет код другу в мессенджер.
4. **Второй** вставляет этот код, жмёт «Продолжить» — приложение выдаёт
   ответный код, его нужно отправить обратно.
5. **Первый** вставляет ответный код, жмёт «Продолжить» — разговор пошёл.
6. В разговоре можно выбрать микрофон и устройство вывода, отрегулировать
   громкости, выключить микрофон. Окно спокойно живёт на заднем плане.

Код подключения содержит ключ сессии — передавайте его только в доверенном
мессенджере. Тот, у кого есть код, может подключиться к разговору.

## Если связь не установилась

Пробитие NAT покрывает подавляющее большинство домашних сетей. Не соединяется
в двух редких случаях:

- у **обоих** жёсткий симметричный CGNAT (типично для мобильного интернета);
- провайдер блокирует UDP между абонентами.

План Б — крошечный релей на VPS (добавим позже, если понадобится).

## Сборка

Нужны: Go 1.26+, Xcode CLT (macOS), mingw-w64 (для сборки .exe с мака).

```bash
./build.sh
```

Собирает `dist/Voice2Us.app` (macOS, arm64) и `dist/Voice2Us.exe` (Windows, x64).

Полезно: `./voice2us --devices` — напечатать список аудиоустройств и выйти.

## Тесты

```bash
go test ./...
```

Прогоняет сессию «Аня ↔ Боря» по UDP-петле: рукопожатие, шифрованный звук
в обе стороны, RTT, корректное завершение.

## Как устроено (кратко)

- `internal/stun` — минимальный STUN-клиент (RFC 5389 Binding).
- `internal/proto` — формат кода подключения, шифрование, сессия:
  пробитие NAT одновременной отправкой, keepalive, ping/pong, bye.
- `internal/audio` — miniaudio: захват и воспроизведение на независимо
  выбранных устройствах, кольцевые буферы, джиттер-буфер с предбуфером 30 мс.
- `ui.go` — интерфейс на Fyne.

Пакет в сети: `[4 байта счётчика][ChaCha20-Poly1305-шифротекст]`, nonce
неявный (направление + счётчик), ключи сторон выводятся из ключа сессии
через HKDF. Повторы и устаревшие пакеты отбрасываются.
